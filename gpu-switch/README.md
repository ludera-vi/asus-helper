# gpu-switch — Eco-режим NVIDIA для ноутбуков ASUS в Linux

Полностью выключает видеокарту NVIDIA **через BIOS** и включает её обратно **без перезагрузки**, как режим
**Eco / Standard в G-Helper** на Windows. Когда карта выключена, Linux её не видит: ни программа, ни драйвер,
ни события батареи не могут её разбудить. Это удобно, когда работаешь от батареи.

## Что входит

| Что | Зачем |
|---|---|
| `gpu-eco` | команда: `off` — выключить NVIDIA, `on` — включить, `status` — состояние |
| Значок **«GPU»** на панели KDE | видно состояние, переключение в один клик; там же переключение частоты экрана (например, 240 ↔ 60 Гц) |
| Сервис `gpu-eco-fixup` | быстрый выход из сна, если ноутбук включили в режиме Eco (см. «Как это работает») |
| Ярлык **«NVIDIA Eco»** в меню | переключение из меню приложений (правый клик → действия) |
| Рабочий стол всегда на встроенной видеокарте *(по желанию)* | рабочий стол перестаёт «держать» NVIDIA, и её можно выключать одной кнопкой, не выходя из системы. Минус: HDMI (обычно подключён к NVIDIA) не работает, пока настройка включена |
| Программы по умолчанию на встроенной видеокарте + `prime-run` *(по желанию)* | браузер, плеер и мессенджеры не будят NVIDIA. На NVIDIA работает только то, что запущено через `prime-run` (игры, Steam, Resolve), как в Windows |

## Требования

- **Ноутбук ASUS** с NVIDIA и функцией отключения dGPU (ROG, TUF, Zephyrus, Strix, Flow и т. п.: всё,
  где в G-Helper / Armoury Crate есть режим **Eco**).
- **MUX в гибридном режиме** (Optimus / Standard), а не Ultimate. В Ultimate выключать NVIDIA нельзя.
- **Arch Linux или производные** (CachyOS, EndeavourOS, Manjaro, Garuda…). На других дистрибутивах тоже
  работает, но пакеты придётся ставить вручную.
- Ядро с `asus-armoury` (новые ядра) или `asus-wmi` (старые). Проверка:
  `ls /sys/class/firmware-attributes/asus-armoury/attributes/dgpu_disable` или
  `ls /sys/devices/platform/asus-nb-wmi/dgpu_disable`.
- Драйвер NVIDIA (`nvidia-open` / `nvidia-open-dkms`).
- **KDE Plasma 6 на Wayland**: для значка и режима «рабочий стол только на iGPU».
  В других окружениях работают команда и ярлык.

Проверено: ASUS ROG Zephyrus G16 GU605MZ (Intel Core Ultra + RTX 4080), CachyOS, ядро 7.2,
KDE Plasma 6.7 Wayland, nvidia-open 615.

## Установка

```bash
git clone <адрес репозитория> gpu-switch
cd gpu-switch
./install.sh
```

Установщик:
1. проверит систему и сразу скажет, если что-то не подходит;
2. покажет, что собирается установить, и спросит про необязательные пункты;
3. предложит сделать снимок системы, если стоит snapper;
4. попросит пароль sudo один раз и установит всё;
5. проверит результат и покажет итог.

Ничего не меняется, пока ты не ответишь «да» на последний вопрос. Журнал установки:
`~/.cache/gpu-switch-install.log`.

**После установки:**
1. Выйди из сеанса и войди снова, если включал пункты про рабочий стол и программы.
2. Добавь значок: правый клик по панели → «Добавить или изменить виджеты» → **NVIDIA Eco** → перетащи на панель.

Повторный запуск `./install.sh` обновляет установленное.

## Как пользоваться

### Значок на панели

| Вид | Значит |
|---|---|
| бледная перечёркнутая «GPU» | NVIDIA выключена (Eco), Linux её не видит |
| «GPU» в рамке | NVIDIA включена и спит (почти не тратит энергию) |
| **залитая пульсирующая «GPU»** | NVIDIA работает прямо сейчас |

- **Наведи** на значок, и в подсказке будет видно, какие программы используют NVIDIA.
- **Нажми**, и откроется окошко: состояние, кнопка включения или выключения, а пока карта работает,
  ещё нагрузка, ватты и память.
- Если выключению мешает программа, будет видно, какая, и появится кнопка «Закрыть эти программы и выключить».
- Внизу окошка: текущая частота встроенного экрана и кнопка **«Переключить на 60 Гц»** / **«…на 240 Гц»**.
  Разрешение не меняется, частоты берутся из режимов экрана (минимальная и максимальная). На батарее
  60 Гц заметно экономят энергию. Это обычная настройка KDE (`kscreen-doctor`), она сохраняется и после
  перезагрузки.

### Команды

```bash
gpu-eco status        # подробное состояние
gpu-eco off           # выключить NVIDIA (откажется, если её кто-то использует, и покажет кто)
gpu-eco off --force   # закрыть программы на NVIDIA и выключить
gpu-eco on            # включить NVIDIA обратно (гибрид)
gpu-eco state         # одно слово: off / suspended / active / missing
gpu-eco who           # какие твои программы сейчас используют NVIDIA
gpu-eco fixup         # убрать с шины выключенную в BIOS карту (обычно это делает сервис сам)
```

Пароль не нужен: установщик разрешил запускать без пароля **только** эту команду.
Состояние сохраняется в BIOS: после перезагрузки карта останется в том же режиме. Это тот же флаг,
что у G-Helper, поэтому режим общий с Windows.

### Запуск программ на NVIDIA

Если ты включил пункт «программы по умолчанию на iGPU», всё работает на встроенной видеокарте.
Чтобы запустить программу на NVIDIA:

```bash
prime-run программа           # например: prime-run steam, prime-run resolve
```

**Ярлык, который всегда запускается на NVIDIA:** скопируй ярлык программы в
`~/.local/share/applications/` и допиши `prime-run ` в начало строки `Exec=`:

```bash
cp /usr/share/applications/steam.desktop ~/.local/share/applications/
# в ~/.local/share/applications/steam.desktop:  Exec=prime-run /usr/bin/steam %U
```

Если NVIDIA выключена, `prime-run` предупредит и запустит программу на встроенной видеокарте.

Проверка: `glxinfo -B | grep renderer` покажет iGPU, а `prime-run glxinfo -B | grep renderer` покажет NVIDIA.

## Как это работает

`gpu-eco off` повторяет то, что делают G-Helper и supergfxctl, но без выхода из сеанса:
1. проверяет MUX и то, что NVIDIA никто не использует;
2. останавливает `nvidia-powerd` / `nvidia-persistenced`;
3. выгружает драйвер (`nvidia_drm`, `nvidia_modeset`, `nvidia_uvm`, `nvidia`);
4. убирает карту и её звук с шины PCI;
5. пишет `1` в `dgpu_disable`, и BIOS снимает с карты питание.

`gpu-eco on`: `dgpu_disable = 0` → пересканирование шины PCI → загрузка драйвера → запуск сервисов.

Если любой шаг не удался, скрипт возвращает всё как было и пишет причину. Журнал: `journalctl -t gpu-eco`.

**Выход из сна после перезагрузки в Eco.** Если включить ноутбук, когда в BIOS стоит Eco, BIOS всё равно
показывает NVIDIA на шине PCI, но без питания. Драйвер её не находит («fallen off the bus»), а ядро при
каждом выходе из сна ждёт её 65 секунд. Сервис `gpu-eco-fixup` при загрузке и перед каждым сном запускает
`gpu-eco fixup`, и эта команда убирает такую карту с шины, как `gpu-eco off`. `gpu-eco on` включает её как
обычно. Когда NVIDIA включена, сервис ничего не делает.

Без пункта «рабочий стол только на iGPU» рабочий стол KDE держит NVIDIA открытой, и `gpu-eco off`
откажется работать (покажет `kwin_wayland`). В этом случае выключать придётся после выхода из сеанса.

**Сколько это экономит.** Спящая NVIDIA (D3cold) и так почти ничего не тратит. Eco убирает её
периодические пробуждения (несколько ватт на секунды каждые 1–2 минуты) и **гарантирует**, что карта
не проснётся. Обычно разница от 0,5 до 1 Вт, а при «шумных» программах больше.

## Что изменяет установщик

| Файл | Что это |
|---|---|
| `/usr/local/bin/gpu-eco` | сама команда |
| `/etc/sudoers.d/gpu-eco` | запуск `gpu-eco` без пароля |
| `/etc/systemd/system/gpu-eco-fixup.service` | `gpu-eco fixup` при загрузке и перед сном |
| `/etc/udev/rules.d/61-igpu-symlink.rules` | постоянное имя `/dev/dri/igpu` для встроенной видеокарты |
| `~/.config/environment.d/90-kwin-igpu.conf` | `KWIN_DRM_DEVICES=/dev/dri/igpu`: KWin только на iGPU |
| `~/.config/environment.d/91-igpu-apps.conf` | EGL / GLX / Vulkan по умолчанию на iGPU |
| `~/.local/bin/prime-run` | запуск на NVIDIA (снимает настройки из файла выше) |
| `~/.local/share/applications/gpu-eco.desktop` | ярлык в меню |
| `~/.local/share/plasma/plasmoids/org.vi.gpueco` | значок на панели |

## Если что-то пошло не так

### После входа в сеанс чёрный экран или сразу выкидывает обратно
Скорее всего, проблема в настройке «рабочий стол только на iGPU».
1. Нажми **Ctrl+Alt+F3**, войди логином и паролем.
2. Выполни:
   ```bash
   rm ~/.config/environment.d/90-kwin-igpu.conf ~/.config/environment.d/91-igpu-apps.conf
   sudo systemctl restart display-manager
   ```
3. Войди как обычно, затем запусти `./uninstall.sh` или напиши issue с выводом `ls -l /dev/dri/`.

### Не работает внешний монитор через HDMI
На многих ASUS HDMI подключён к NVIDIA, а рабочий стол настроен только на iGPU. Временно отключи настройку:
```bash
mv ~/.config/environment.d/90-kwin-igpu.conf ~/.config/environment.d/90-kwin-igpu.conf.off
```
Затем выйди из сеанса и войди снова, и не забудь включить NVIDIA (`gpu-eco on`). Чтобы вернуть настройку,
переименуй файл обратно. Порты USB-C / Thunderbolt часто подключены к iGPU и работают в любом режиме.

### `gpu-eco off` отказывается: «NVIDIA используют эти программы»
Закрой перечисленные программы или выполни `gpu-eco off --force`. Если в списке `kwin_wayland`, значит, не
включён пункт «рабочий стол только на iGPU» (или ты не перезашёл в сеанс после установки).

### Выход из сна занимает минуту и больше
Проверь, что сервис включён: `systemctl is-enabled gpu-eco-fixup` (должно быть `enabled`). Если в журнале
`journalctl -k -b | grep "not ready"` есть строки с `01:00.0`, значит, карта осталась на шине: запусти
`gpu-eco fixup` и напиши issue.

### `gpu-eco on`: «карта не появилась»
Перезагрузи ноутбук: BIOS уже включил карту, и после загрузки она будет на месте.

### NVIDIA пропала совсем (даже после перезагрузки)
Значит, в BIOS осталось `dgpu_disable = 1`. Включи:
```bash
gpu-eco on
# если gpu-eco уже удалён:
echo 0 | sudo tee /sys/class/firmware-attributes/asus-armoury/attributes/dgpu_disable/current_value
# (на старых ядрах: echo 0 | sudo tee /sys/devices/platform/asus-nb-wmi/dgpu_disable)
```
Затем перезагрузись. Ещё можно переключить режим на Standard в G-Helper на Windows.

### Значка нет в списке виджетов
```bash
systemctl --user restart plasma-plasmashell
```
Ошибки значка: `journalctl --user -b | grep -i gpueco`.

### Программа не запускается или медленно работает после установки
Скорее всего, ей нужна NVIDIA: запусти через `prime-run программа`. Если без пункта
«программы по умолчанию на iGPU» всё было хорошо, удали файл `~/.config/environment.d/91-igpu-apps.conf`
и перезайди в сеанс.

### Откатить всё
- `./uninstall.sh` удалит всё установленное и предложит включить NVIDIA;
- если установщик делал снимок snapper, можно загрузиться в снимок
  «before gpu-switch install» из меню загрузчика.

## Конфликты

- **supergfxctl** устарел и делает то же самое по-своему, поэтому выключи его:
  `sudo systemctl disable --now supergfxd`.
- **envycontrol** должен быть в режиме `hybrid` (или удалён).
- **asusd / rog-control-center** не мешают: подсветку, вентиляторы и профили можно настраивать ими как раньше.
