# asus-osd — карточки KDE для Fn+F5 и подсветки клавиатуры на ASUS

На ноутбуках ASUS под Linux при нажатии **Fn+F5** (смена режима производительности) и клавиш
**подсветки клавиатуры** всё переключается, но KDE не показывает свои карточки, хотя для яркости
экрана и громкости показывает. asus-osd возвращает эти карточки.

## Почему карточек нет

- **Режимом (Fn+F5) управляет asusd.** KDE узнаёт о режимах только от `power-profiles-daemon`,
  а на системах с asusd он обычно отключён, чтобы они не спорили друг с другом.
- **Подсветкой клавиатуры управляет само ядро** (драйвер ASUS). Оно меняет яркость, но UPower,
  через который KDE следит за подсветкой, об этом не узнаёт.

asus-osd слушает сигналы asusd о смене режима и уведомления ядра о подсветке, а при изменении
просит KDE показать его же стандартную карточку.

## Нагрузка на систему

Нулевая. asus-osd ничего не опрашивает по таймеру: он спит и просыпается только когда asusd
сообщает о смене режима или ядро сообщает о нажатии клавиши подсветки. В простое процессор
не используется, памяти занято около 30 МБ (Python).

## Требования

- Ноутбук ASUS
- **KDE Plasma 6**
- **asusd** (пакет `asusctl`) для карточки режима. Без него будет работать только подсветка.
- Python 3 и `python-gobject` (установщик предложит поставить, если его нет)

Проверено: ASUS ROG Zephyrus G16 GU605MZ, CachyOS, KDE Plasma 6.7, asusctl 6.5.

## Установка

```bash
cd lighting_keyboard
./install.sh
```

Установщик проверит систему, покажет, что сделает, и после согласия установит. В конце появится
тестовая карточка. Перезаходить в систему не нужно. Пароль sudo понадобится только если надо
доставить `python-gobject`.

Повторный запуск `./install.sh` обновляет установленное.

## Как пользоваться

Никак, всё работает само:

| Нажатие | Карточка |
|---|---|
| **Fn+F5** | режим: Тихий (энергосбережение) / Сбалансированный / Производительность |
| **клавиши подсветки клавиатуры** | уровень подсветки в процентах |

Карточка режима появляется и тогда, когда asusd сам меняет режим при подключении или отключении
зарядки, и когда режим меняют в rog-control-center. Так всегда видно, какой режим сейчас включён.

## Что устанавливается

| Файл | Что это |
|---|---|
| `~/.local/bin/asus-osd` | сам помощник |
| `~/.config/systemd/user/asus-osd.service` | служба, которая запускает его при входе в систему |

Всё ставится только для твоего пользователя, системные файлы не меняются.

## Если что-то не работает

**Проверить, работает ли служба:**
```bash
systemctl --user status asus-osd
journalctl --user -u asus-osd -n 30
```

**Перезапустить:**
```bash
systemctl --user restart asus-osd
```

**Нет карточки режима при Fn+F5.** Проверь, что asusd работает: `systemctl status asusd`. Затем
проверь, что asusd видит нажатие: `gdbus monitor --system --dest xyz.ljones.Asusd`, нажми Fn+F5,
и должна появиться строка с `PlatformProfile`.

**Нет карточки подсветки.** Проверь, что ядро сообщает о нажатиях:
```bash
cat /sys/class/leds/*::kbd_backlight/brightness_hw_changed
```
Если файла нет, значит, ядро слишком старое или модель не поддерживает уведомления.
Ошибка `No data available` — это нормально, пока после загрузки ни разу не нажимали клавишу подсветки.

**Карточка режима появляется дважды.** Значит, включён `power-profiles-daemon`, и KDE показывает
свою карточку сам. Тогда asus-osd для режима не нужен.

**Проверить, что KDE вообще показывает карточки:**
```bash
busctl --user call org.kde.plasmashell /org/kde/osdService org.kde.osdService powerProfileChanged s performance
```

## Удаление

```bash
./uninstall.sh
```
